# 4.3 Office 技巧

## Office Word

### 数据块模式

* 按住「Option」键进入块选中



### 表格精细对齐

* 按住「Option」选中单元格进行精细自动对齐



## Office Excel

### 隔行填充颜色

```
1. 选中整个数据区域，【开始】-【条件格式】-【新建规则】
2. 选择【使用公式确定要设置格式的单元格】，后设置公式「=MOD(ROW(),2)=0」
3. 点击【格式】-切换到【填充】，选择一个设定的颜色
4. 点击【确定】
```



#### 条件判选整行数据

```
1. 选中整个数据区域，【开始】-【条件格式】-【新建规则】
2. 选择【使用公式确定要设置格式的单元格】，后设置公式 e.g.「=$C3=0」
3. 点击【格式】-切换到【填充】，选择一个设定的颜色
4. 点击【确定】
```



### 平替 LOOKUP 函数

```
=INDEX(查找列, MATCH(查找值, 查找范围, 0))
```



### 西文引号替换为中文弯引号

```
1.【文件—选项—校对—自动更正】中关闭「直引号替换为弯引号」
2.【替换】打开【使用通配符】，查找内容："(*)"；替换为：“\1”
3.【替换】打开【使用通配符】，查找内容：[“”]
4. 选择【特殊格式—字体】中文字体【新罗马】西文字体【新罗马】
5. 替换为：^&，特殊格式中文字体【目标字体，如宋体】西文字体【目标字体，如宋体】
```

* 修订模式下字符渲染可能会失效，但可以正确替换，退出修订后即可渲染正常。



### 启用下拉菜单多选

通过宏设置，可以实现下拉菜单的多选功能，步骤如下：

```
1.【设置-工具-宏】中启用新的宏；
2. 粘贴下面这段代码；
3. 保存关闭即可。
```

```vb
Private Sub Worksheet_Change(ByVal Target As Range)
    Dim xValue1 As String
    Dim xValue2 As String
    Dim delimiter As String
    Dim hasValidation As Boolean
    
    ' 如果一次更改了多个单元格，直接退出
    If Target.Count > 1 Then Exit Sub
    
    delimiter = ", " ' 分隔符，你可以自行修改
    
    ' 检查当前更改的单元格是否设置了数据验证（下拉菜单）
    On Error Resume Next
    hasValidation = (Target.Validation.Type = xlValidateList)
    On Error GoTo 0
    
    ' 如果当前单元格不是下拉菜单，直接退出，不影响普通单元格的正常输入
    If Not hasValidation Then Exit Sub
    
    ' 以下为下拉菜单多选逻辑
    Application.EnableEvents = False
    
    xValue2 = Target.Value      ' 获取刚刚输入/选择的新值
    Application.Undo            ' 撤销，获取原来的值
    xValue1 = Target.Value      ' 获取原来的值
    Target.Value = xValue2      ' 恢复刚刚输入/选择的新值
    
    If xValue1 <> "" And xValue2 <> "" Then
        ' 如果原来的值里还没有包含新值，则拼接
        If Not (xValue1 = xValue2 Or _
                InStr(1, xValue1, delimiter & xValue2) > 0 Or _
                InStr(1, xValue1, xValue2 & delimiter) > 0) Then
            Target.Value = xValue1 & delimiter & xValue2
        Else
            Target.Value = xValue1
        End If
    End If
    
    Application.EnableEvents = True
End Sub
```
